> ### `[ ACTIVE ]` Sensor Reliability in Autonomous Robots
> **ICARUS Lab · McNair Scholars Program** — Mentor: Prof. Ioannis Zografopoulos
>
> How do sensor-based navigation systems in autonomous robots respond to manipulated or incorrect sensor input — and how do we make them more reliable? Testing a **TurtleBot3 Burger** (ROS/ROS2, LiDAR) under delayed, noisy, and spoofed sensor conditions using **Opal-RT** hardware-in-the-loop, working toward validation and filtering methods for safer **assistive robotics**.
>
> `TurtleBot3` `ROS2` `LiDAR` `Opal-RT` `Python`

> ### `[ COMPLETE ]` Hybrid RF / Optical Indoor Localization
> **UCaN Lab** — Advisor: Prof. Michael Rahaim
>
> Fusing **RF fingerprinting** with **Visible Light Positioning** on an SDR testbed so localization stays reliable where GPS fails. My portion was the **machine learning**: collecting and analyzing wireless signal data in MATLAB, and modeling localization and environment classification.
>
> **Result:** 85.2% motion-classification accuracy at a 2 ms window vs. 51.0% at 20 ms.
>
> `MATLAB` `Python` `SDR` `GNU Radio` `OWC/VLP`
